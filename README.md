# HackerRank (C)

Solutions to the HackerRank problems from my college's Peacemaker program — around 120 questions given by my professor, all solved in C during my first semester.

This is my first time solving and organizing a set of questions like this, so it's more of a practice log than a tutorial — a record of how I was learning C, one problem at a time.

## What's inside

The repo is split into folders by topic:

| Folder | What it covers |
|---|---|
| `Basics` | Simple I/O, variables, type conversions |
| `If_Else` | Conditional logic problems |
| `SwitchCase` | Switch-case based problems | 
| `Loops` | For/while loop practice |
| `Arrays` | Array manipulation |
| `Numbers` | Number theory type problems (Harshad numbers, etc.) |
| `Bitwise` | Bit manipulation |
| `Patterns` | Pattern printing |

Each folder has the individual problem solutions as separate `.c` files, named after the problem.

## Why this exists

Our college uses HackerRank to assign and track practice problems as part of coursework, and this is where I keep my solved code instead of losing it in random files on my laptop. It's also easier to just push here after solving something on the platform.

## Note

These are my own solutions written while learning C — if you're doing the same course/problems, use this to understand the logic rather than copy-pasting it directly.
